This folder contains code for the automatic sleep scoring mcRBM algorithm.

Using 2 raw lfp signals from the hippocampus and  cortex, this pipeline will train a model and run it to obtain 
automatic sleep scoring of a sleep period. Sleep will be classified in 5 states: Wakefulness, N1, N2, N3 and REM.

In order, the repositories used should be:

1- hdf5_files

2- mcRBM

3- StateInferrence

4- FurtherAnalysis
